## 🌟 Key Highlights & Features

- **🎨 Modern Dark Aesthetic**: Crafted with HSL / OKLCH tailored dark theme, glowing accents, and glassmorphic card designs.
- **✨ Interactive Micro-Animations**: Powered by Framer Motion, featuring smooth section entrance animations, interactive card hover glow, 3D mouse parallax tilt, and ambient floating particles.
- **⚡ Cinematic Loading Screen**: High-precision animated preloader with progress tracking and smooth layout reveal.
- **📱 Fully Responsive**: Pixel-perfect layout tailored for mobile devices, tablets, laptops, and ultra-wide screens.
- **📄 Downloadable Resume & PDF Verification**: Direct access to verifiable credentials, certificates, and the latest professional resume.
- **🚀 SEO & Performance Optimized**: Semantic HTML5 hierarchy, OpenGraph metadata, fast asset loading, and optimized web fonts.

## 💻 Local Development Setup

Follow these steps to run the portfolio on your local machine:

### 1. Clone the repository
```bash
git clone https://github.com/rahulsinghkushwaha232/my-portfolio.git
cd my-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm start
```
